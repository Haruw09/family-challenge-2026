# family_challenge_2026 🌍

Привет! Рада, что ты прошел задание, однако это еще не все: чтобы узнать последний секретик тебе необходимо выполнить следующие шаги. Добавь в этот репозиторий одну свою фотку с геопозицией из точного места прочтения письма. Когда наберётся 8 стран — откроется секрет.

> ⚠️ **НЕ ПОДСМАТРИВАЙ В ФАЙЛЫ В ПАПКЕ `quest/`!** Там реализована логика
> подсчёта и открытия секретика — если туда заглянуть, будет неинтересно.
> Просто выполняй шаги ниже и запускай `reveal.py`.

## Что нужно сделать

1. Склонируй репозиторий (если ещё не склонировал):

   ```bash
   git clone <ссылка на репозиторий>
   cd family_challenge_2026
   ```

2. Установи зависимости (один раз):

   ```bash
   pip install -r requirements.txt
   ```

3. Скопируй папку-шаблон `submissions/_template/` в `submissions/<твоё_имя>/`
   (латиницей или кириллицей — как удобно) и положи туда:
   - файл `entry.yaml`, заполненный по образцу;
   - саму фотографию (jpg/png), имя файла должно совпадать с полем `photo`
     в `entry.yaml`.

   Пример `submissions/vasya/entry.yaml`:

   ```yaml
   name: Вася
   country: Франция
   lat: 48.8566
   lon: 2.3522
   photo: photo.jpg
   ```

   Координаты — широта/долгота той точки, где сделано фото (можно взять из
   геометки телефона или посмотреть на карте, зажав точку).

4. Закоммить и запушь свою папку (или открой pull request — как договорились):

   ```bash
   git add submissions/<твоё_имя>
   git commit -m "add: <твоё_имя>, <страна>"
   git push
   ```

5. Подтяни изменения остальных и запусти скрипт из корня репозитория:

   ```bash
   git pull
   python reveal.py
   ```

   Скрипт спросит твоё имя (как в `entry.yaml`) и покажет твой результат.
   Если вы ещё не все закончили — секретик не откроется до конца, но
   ты увидишь фотки всех, кто уже добавил свою точку. Возвращайся и
   перезапускай скрипт, когда кто-то ещё добавит фото.

## Требования

- Python 3.9+
- Интернет-соединение (для определения адреса по координатам)
